# AI Usage

AI-ассистент использовался в этом репозитории для:

- анализа `web-technologies-syllabus.html`;
- составления `docs/IMPLEMENTATION_PLAN.md`;
- подготовки шаблона отчета практики 1;
- создания семантического HTML-каркаса лабораторной 1 по требованиям syllabus;
- подготовки чек-листа проверок.

AI не использовался для выдумывания результатов DevTools, W3C Validator или Lighthouse. Все такие результаты должны быть сняты вручную и записаны как реальные измерения.

Студент должен быть готов объяснить каждую строку кода и разметки на защите.
