# BookNest

Накопительный учебный проект курса «Современные веб-технологии». Текущая работа: ЛР4, интеграция с Open Library. HTML, CSS, JavaScript ESM без React, TypeScript, runtime-зависимостей и серверной части.

## Запуск

~~~powershell
npm start
~~~

Открыть http://127.0.0.1:8130/. Проверено на Node.js 22.14.0. Установка пакетов для запуска не требуется. tools/serve.mjs только раздаёт статические файлы; это не backend. Через file:// ESM не запускается корректно.

## Возможности

- index.html: поиск по названию/автору от двух символов, debounce 350 мс; жанр, электронная доступность, сортировка, сброс, страницы по 20 API-записей.
- Ровно одно состояние: loading, success, empty или error. Разные сообщения Offline, network, 4xx, 5xx, timeout; кнопка «Повторить».
- book.html?id=OL109524W: отдельная загрузка деталей, обработка 404, wishlist.
- Wishlist, фильтры и страница сохраняются в localStorage. Список независим от текущей выдачи.
- loan.html: прежняя учебная форма Solaris; реальную выдачу не оформляет.
- Адаптивность 320 / 375 / 768 / 1440 px, системная светлая/тёмная тема, клавиатурная навигация.

## Архитектура

- api/client.js: единый BASE_URL, URLSearchParams, response.ok, ApiError.status, отмена и тайм-аут 20 секунд.
- api/books.js: серверный поиск и нормализация; детали через Promise.all двух независимых запросов (произведение и поисковые метаданные).
- main.js, detail.js: один state на каждую отдельную страницу; делегирование действий.
- lib/api-state.js: жизненный цикл запросов, защита от устаревших ответов, завершение loading в finally.
- ui/render.js: безопасный DOM, состояния, карточки и восстановление фокуса; без innerHTML.
- api-storage.js: схема v2 со стабильными OL…W и снимками названия/автора. Миграция v1 сохраняет старый ключ; b01…b40 остаются помеченными записями ЛР3 без выдуманного API-ID.
- data/books.js, lib/books.js, storage.js и прежние тесты сохранены для совместимости и миграции. Локальные книги не используются как источник каталога или запасной ответ API.
- Четыре CSS-файла ЛР2 сохраняют токены, Grid/Flexbox и темы.

## Ограничения

- Доступность означает ebook_access:public, а не свободный экземпляр клуба. Рейтинг и его сортировка принадлежат Open Library.
- API иногда возвращает некорректные ID: запрос по 20 записей может дать меньше 20 карточек. Пропуски явно указаны в счётчике.
- Обложки внешние. Незагруженные, ошибочные и однопиксельные изображения скрываются, сведения остаются доступны.
- Учебные отзывы Solaris не показываются для произвольной книги. Отправка отзывов/выдача вне ЛР4.
- При запрете localStorage работа продолжается в памяти. Хранилище привязано к origin; live-синхронизации вкладок нет.
- Ветка lab-4/api основана на lab-3/js-app (51b8886). Предыдущие PR не объединены: нужно учесть зависимости перед PR в main. Push, merge и создание PR не выполнялись.
