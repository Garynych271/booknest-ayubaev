# BookNest

BookNest — накопительный учебный проект курса "Современные веб-технологии".

На текущем этапе реализована лабораторная работа 3: клиентский каталог на JavaScript ESM с 40 локальными книгами пяти жанров, фильтрами и списком желаемого. Адаптивность и две темы ЛР2 сохранены. React, внешний API и backend не используются.

## Страницы

- `index.html` — поиск по названию/автору, жанр, доступность, три сортировки, счётчик, пустое состояние, сброс и wishlist.
- `book.html` — карточка книги.
- `loan.html` — форма выдачи книги.

## Как проверить локально

```powershell
npm start
```

Открыть **http://127.0.0.1:8130/**. Проверено на Node.js 22.14.0; для запуска установка пакетов не требуется. `tools/serve.mjs` только раздаёт статические файлы с корректным MIME для ESM. Это не сервер приложения и не API. Открытие через `file://` больше не подходит для модулей и localStorage.

1. Ввести `мартин`, выбрать «Программирование», «Только доступные» и сортировку по году: останутся две книги.
2. Добавить книгу кнопкой «Хочу прочитать» и перейти к «Мой список» в шапке.
3. Перезагрузить страницу: фильтры и список сохраняются. Сброс очищает фильтры, но не wishlist.
4. Удалить книгу из списка, проверить пустой поиск и клавиатурную навигацию.
5. Проверить 320, 375, 768, 1440 px и обе темы.
6. Открыть [результаты ЛР3](docs/lab3/README.md). Исторические проверки ЛР1/ЛР2 сохранены без изменений.

## Проверки и архитектура

```powershell
npm ci
npm test
npm run lint
```

ESLint является devDependency, runtime-зависимостей нет. В `package-lock.json` зафиксированы версии. Браузерные инструменты установлены отдельно в игнорируемой `.audit-tools/`; команды аудита приведены в отчёте ЛР3.

- `data/books.js`: 40 записей и пять жанров, замороженные объекты и массив.
- `lib/books.js`: чистые выборка, сортировка, нормализация и переключение wishlist.
- `main.js`: единственный `state`, события формы, делегирование кликов, сохранение перед вызовом `render()`.
- `ui/render.js`: единственный `render()`, безопасные DOM-узлы, счётчики, кнопки, восстановление фокуса.
- `storage.js`: чтение/запись ключа `booknest.catalog.v1`, валидация схемы, обработка ошибок.
- `assets/covers/`: 40 локальных типографических учебных обложек; это не фотографии изданий. Генератор: `tools/make-covers.mjs`.

## Стили

- `styles/tokens.css`: 46 дизайн-токенов и тёмная палитра.
- `styles/base.css`: сброс, типографика, `box-sizing`, фокус.
- `styles/layout.css`: Grid/Flexbox, резиновые контейнеры, раскладка от 900 px.
- `styles/components.css`: карточки, навигация и состояния форм.

## Ограничения текущего этапа

- Данные учебные: доступность и рейтинг условные, не результаты внешнего сервиса.
- Карточка `book.html` и форма `loan.html` по-прежнему относятся только к Solaris; ссылки других книг не ведут на неверную detail-страницу. Обработка POST и реальные выдачи вне ЛР3.
- При блокировке localStorage работа продолжается в памяти с видимым сообщением; сохранение между сессиями в этом случае невозможно.
- Данные привязаны к origin (хосту и порту); live-синхронизация уже открытых вкладок не реализована и не требуется ЛР3. Новая вкладка восстанавливает сохранённые данные.
- Обложки всех страниц теперь локальные, дефис в `pattern` ФИО исправлен и проверен. Старые отчёты ЛР2 фиксируют прежнее состояние.
- ЛР1 и ЛР2 ожидают проверки в отдельных PR. Ветка `lab-3/js-app` основана на `lab-2/styles`; перед PR в main нужно учитывать эту зависимость.
