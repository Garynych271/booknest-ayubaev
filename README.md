# BookNest

BookNest — накопительный учебный проект курса "Современные веб-технологии".

На текущем этапе реализована лабораторная работа 2: адаптивная CSS-вёрстка трёх страниц из ЛР1, светлая и тёмная темы. JavaScript и React в приложении отсутствуют.

## Страницы

- `index.html` — каталог книг.
- `book.html` — карточка книги.
- `loan.html` — форма выдачи книги.

## Как проверить локально

1. Открыть `index.html` в браузере.
2. Перейти по навигации на `book.html` и `loan.html`.
3. Проверить формы без заполнения обязательных полей: браузер должен блокировать отправку нативной валидацией.
4. Пройти интерактивные элементы клавишей Tab.
5. Проверить ширины 320, 375, 768 и 1440 px и эмуляцию `prefers-color-scheme` в DevTools.
6. Открыть [результаты ЛР2](docs/lab2/README.md): скриншоты, браузерные проверки и Lighthouse. Исторические проверки HTML без CSS остаются в `docs/lab1/`.

Статические страницы работают через `file://`; сервер для просмотра не нужен. Скрипты аудита из `tools/` сами временно запускают HTTP-сервер и останавливают его после проверки. Установка инструментов описана в отчёте ЛР2 и не добавляет зависимостей приложению.

## Стили

- `styles/tokens.css`: 46 дизайн-токенов и тёмная палитра.
- `styles/base.css`: сброс, типографика, `box-sizing`, фокус.
- `styles/layout.css`: Grid/Flexbox, резиновые контейнеры, раскладка от 900 px.
- `styles/components.css`: карточки, навигация и состояния форм.

## Ограничения текущего этапа

- JavaScript намеренно не добавлен: интерактивность относится к последующим лабораторным.
- React не используется на этом этапе.
- Фильтры и отправка форм остаются HTML-каркасом без обработки данных.
- Часть внешних обложек недоступна из проверочной сети после перенаправления на `archive.org`.
- В исходной ЛР1 обнаружен некорректный `pattern` ФИО. Он сохранён согласно ограничению ЛР2 на изменения HTML; подробности и предлагаемое отдельное исправление в отчёте.
- Ветка `lab-2/styles` основана на `lab-1/markup`; PR ЛР1 ещё должен быть объединён с `main` перед чистым сравнением ЛР2 с `main`.
