# Учебные обложки BookNest

40 локальных PNG, по одному на ID из `data/books.js`. Оригинальные типографические макеты содержат название, автора и жанр. Это учебная визуализация, не репродукции издательских обложек и не изображения, полученные из внешнего API.

Созданы `node tools/make-covers.mjs` в Edge через Playwright. Исходный макет и палитра находятся в этом скрипте. Генерация не требуется для запуска приложения: готовые файлы включены в Git.
