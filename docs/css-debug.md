# Практика 3 и СРС недели 3: связь с ЛР2

Источник: syllabus, разделы 09 (Практика 3), 10 (ЛР2), 11 (СРС), 19 (материалы W3).

В ЛР2 реализованы 46 токенов, шапка Flexbox, каталог Grid с минимумом 260 px, сайдбар от 900 px, прижатый футер, системная тёмная тема. Самостоятельная часть про карточки проверена в браузере: одно название временно заменено 15 словами, высота трёх карточек ряда и нижняя граница кнопок совпадают. Данные: `lab2/browser-results.json`, записи `longTitle`.

## Статус CSS-детектива

Файл преподавателя `broken.css` и контрольные макеты `starter/lab2-styles` отсутствуют в доступных файлах. Исправление пяти конкретных дефектов **не выполнено**. Ниже памятка диагностики, а не отчёт о якобы исправленном файле.

| Тема | Что проверить в DevTools | Принцип исправления |
| --- | --- | --- |
| Специфичность | В Styles найти победившее и зачёркнутое объявление, сравнить специфичность селекторов | Упростить конфликтующие селекторы и устранить источник конфликта без `!important` |
| Порядок | При одинаковой важности, слое и специфичности проверить порядок правил и подключения файлов | Поставить базовые правила перед компонентами; позднее объявление выигрывает при прочих равных |
| `box-sizing` | Сопоставить Computed width с border/padding в Box Model | Применить `border-box`, чтобы padding и border входили в заданный размер |
| Схлопывание `margin` | Проверить вертикальные поля соседних блоков и первого/последнего ребёнка | Для стека использовать Grid/Flexbox и `gap`; при иной задаче осознанно создать новый контекст форматирования |
| Viewport | Проверить наличие meta viewport и реальную CSS-ширину в Device Toolbar | Использовать `width=device-width, initial-scale=1`; это настройка HTML, а не исправление CSS |

В текущей ЛР2 box sizing задан в `base.css`, sibling-spacing выполнен через `gap`, viewport унаследован из ЛР1, ID-селекторов и `!important` нет. Это не доказывает выполнение отсутствующего задания `broken.css`.

## СРС W3

Программа предусматривает чтение MDN CSS layout (Flexbox, Grid), Responsive design; HW «CSS-детектив + дизайн-токены», доработку ЛР и подготовку к защите. Токены и доработка ЛР выполнены в этой ветке. Личное чтение студентом, квиз и недоступные материалы преподавателя не отмечены как выполненные.

Официальные материалы для подготовки:

- [MDN: CSS layout](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout)
- [MDN: Grid columns и minmax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/grid-template-columns)
- [MDN: Responsive design](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design)
- [MDN: prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)

Дополнительные задания (ручной переключатель темы, скелетоны, печать, сравнение полностью без media queries) не выполнялись.
