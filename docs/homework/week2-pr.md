# Домашнее задание W2: профиль читателя BookNest

Добавлен четвёртый HTML5-экран BookNest с данными читателя, историей выдач и формой смены пароля. Страница связана с тремя экранами ЛР1 и не содержит CSS, JavaScript или React.

## Что сделано

- Семантические `header`, `nav`, `main`, `section`, `footer`, `dl` и таблица с заголовками строк и столбцов.
- Один `h1`, последовательные `h2`, хлебные крошки и `aria-current`.
- Три подписанных password-поля с `name`, `required`, ограничениями длины и корректным `autocomplete`.
- Ссылка на профиль добавлена в общую навигацию `index.html`, `book.html` и `loan.html`.
- Сохранены исходные отчёты, скриншоты и browser smoke-check в `docs/homework/week2/`.

## Как проверить

1. Запустить `python -m http.server 8080 --bind 127.0.0.1`.
2. Открыть `http://127.0.0.1:8080/profile.html`.
3. Проверить переходы между четырьмя страницами и пройти профиль клавишей Tab.
4. Отправить пустую форму и проверить фокус на текущем пароле.
5. Открыть отчёты и снимки из `docs/homework/week2/`.
