# PR: Лабораторная 1 — семантический интерфейс BookNest

## Что сделано

- Добавлены три HTML-страницы BookNest без CSS и JavaScript.
- Добавлены README, AI_USAGE и чек-лист доказательств.
- Страницы связаны навигацией.
- Формы используют нативную HTML-валидацию.

## Как проверить

1. Открыть `index.html`.
2. Перейти по ссылкам на `book.html` и `loan.html`.
3. Проверить отправку форм с пустыми обязательными полями.
4. Пройти страницы клавишей Tab.
5. Прогнать W3C Markup Validator.
6. Прогнать Lighthouse Accessibility.

## Самопроверка

- [ ] Один `h1` на страницу.
- [ ] Иерархия заголовков без пропусков.
- [ ] Все поля форм имеют `label` и `name`.
- [ ] Нет inline styles/CSS/JS/React.
- [ ] Использованы обязательные семантические элементы.
- [ ] Изображения имеют `alt`, `width`, `height`.
- [ ] Реальные результаты W3C/Lighthouse внесены в `docs/lab1/README.md`.
