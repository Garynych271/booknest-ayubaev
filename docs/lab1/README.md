## Самопроверка требований

- [ ] Ровно один `h1` на страницу.
- [ ] Нет CSS, inline styles и атрибутов оформления.
- [ ] Нет React и JavaScript.
- [ ] Есть `lang="ru"`, charset, viewport и `title`.
- [ ] Навигация связывает все три страницы.
- [ ] Использованы обязательные элементы: `header`, `nav`, `main`, `article`, `section`, `aside`, `footer`, `figure`, `time`, `dl`.
- [ ] Все поля форм имеют `label` и `name`.
- [ ] Используется нативная валидация.
- [ ] Все изображения имеют `alt`, `width`, `height`.
