# ЛР2: адаптивная вёрстка и дизайн-токены BookNest

Три семантические HTML-страницы получили mobile-first стили: каталог с фильтрами, карточка книги и форма выдачи. На 375 px каталог одноколоночный, на 768 px двухколоночный, на 1440 px содержит три карточки в ряд и боковые фильтры. Тёмная тема использует системную настройку.

## Изменения

- Четыре CSS-файла, 46 токенов, две media queries, Grid/Flexbox и `gap`.
- Равная высота карточек, кнопки снизу, футер при коротком содержимом.
- Фокус 3 px, состояния invalid/disabled, отсутствие анимации при любых настройках reduced motion.
- В HTML добавлены только классы и подключения CSS; содержимое и семантика сохранены.
- README, AI_USAGE, воспроизводимые аудиты, доказательства и связанная памятка по практике 3.

## Проверка

Открыть `index.html`, пройти навигацию и Tab. Проверить 320 / 375 / 768 / 1440 px и обе темы. Команды автоматического воспроизведения и все ограничения: [docs/lab2/README.md](lab2/README.md).

Реальные Edge 155 + Lighthouse 12.8.2, 17.10.2026. Сохранены 6 JSON/HTML отчётов Lighthouse, 18 полных скриншотов и 2 снимка фокуса. Дополнительно 486 замеров ширины без горизонтального overflow. Проверены Grid-колонки, навигация, клавиатурный фокус, форма email, disabled, карточки с длинным названием и короткий main.
