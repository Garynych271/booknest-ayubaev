# ЛР3: локальный каталог BookNest с фильтрами и wishlist

Статический каталог заменён клиентским ESM-приложением с 40 локальными книгами пяти жанров. Поиск по названию/автору, жанр, доступность и три сортировки работают совместно; счётчик и пустое состояние обновляются сразу. Wishlist и фильтры сохраняются после перезагрузки, сброс фильтров не удаляет список книг.

## Изменения

- Один state в main.js, один render в ui/render.js, чистые функции в lib/books.js, данные отдельно.
- Одно событие input для фильтров; делегирование действий карточек и wishlist через main/closest.
- Безопасные DOM-операции, aria-pressed, доступные имена кнопок и восстановление фокуса.
- Валидация localStorage, восстановление значений по умолчанию, работа в памяти при запрете записи.
- 40 локальных типографических учебных обложек; внешних запросов приложения нет.
- Адаптивность и две темы ЛР2 сохранены. Исправлен унаследованный pattern ФИО.
- ESLint, функциональные и модульные тесты, README, AI_USAGE и реальные доказательства.
