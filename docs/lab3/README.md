| «Хочу прочитать», визуальное состояние, aria-pressed | Кнопки переключаются в «В моём списке»; доступное имя включает видимый текст и название книги |

| localStorage: фильтры и wishlist | Ключ `booknest.catalog.v1`, version=1; reload и новая вкладка восстанавливают данные |
| ESM, разделение данных/логики/UI | `data/books.js`, `lib/books.js`, `ui/render.js`, `main.js`, отдельный `storage.js` |

| Безопасный DOM | `textContent`, `createElement`, `cloneNode` из статического template, `replaceChildren`; HTML-подобный запрос не создаёт элементы |
| Безопасное хранилище | try/catch на чтение, JSON.parse и запись; проверка типов, разрешённых значений, версии и ID, удаление дублей |
| Одно событие фильтров | Только `input` меняет фильтры; submit отдельно предотвращает навигацию, reset сбрасывает состояние |
| Три проверки чистых функций в браузере | `consoleSelections` в browser-results.json: `['b01']`, `['b40','b33']`, `[]` |
| ESLint и чистая консоль | 0 errors / 0 warnings; браузерные error/warning/pageerror отсутствуют |
| Адаптивность и темы ЛР2 | 24 комбинации: 3 страницы × 4 ширины × 2 темы, без overflow, все изображения загрузились |

## Поток данных

```text
data/books.js ──> lib/books.js (чистая выборка)
                       │
localStorage ──> storage.js ──> main.js: state
                                 │
             input/reset/click -> update()
                                 │
                      savePreferences(state)
                                 │
                      ui/render.js: render()
                                 │
                 DOM, aria-pressed, счётчики, фокус
```

В `lib/` функции создают новые массивы/объекты. `filter(...).sort(...)` сортирует результат filter, не исходный массив. Дополнительный порядок по title/id делает равные рейтинги/годы предсказуемыми. После перерисовки активная wishlist-кнопка восстанавливает фокус; при удалении фокус переходит к оставшейся кнопке либо заголовку пустого списка.

Обработчик формы читает значения полей и нормализует их; DOM меняет только `render()`. `storage.js` расположен вне `lib/`, так как чтение/запись хранилища являются побочными эффектами.

## Исправленные проблемы

- Прежние внешние обложки зависели от недоступного archive.org. Теперь все страницы используют локальные PNG, внешних запросов нет. Это оригинальные учебные типографические обложки, не сканы изданий.
- Унаследованный pattern ФИО с неэкранированным дефисом исправлен. Edge отвергает `123` и принимает `Анна-Мария Иванова`.
- Доступное имя выбранной wishlist-кнопки приведено в соответствие с её видимым текстом.
- Фокус после замены DOM сохраняется; пустой wishlist имеет предсказуемую точку фокуса.
- Повреждение/недоступность хранилища и ошибки записи обрабатываются без исключений в консоли.

Первый запуск `node --test` в ограниченной среде завершился `spawn EPERM`. Тесты затем реально выполнены с разрешённым запуском процессов и прошли; сохранённый unit-tests.txt относится к успешному запуску. Результаты не исправлялись вручную ради успешного статуса.

## Воспроизведение

Из корня проекта:

```powershell
npm ci
npm test
npm run lint
npm start
```

Приложение: `http://127.0.0.1:8130/`. Для запуска достаточно `node tools/serve.mjs`, без установки devDependencies. HTTP нужен для ESM; backend и API отсутствуют. Параметр `PORT` позволяет выбрать другой свободный порт.

Браузерный аудит требует локальный Edge и отдельные инструменты, не входящие в приложение:

```powershell
npm.cmd install --prefix .audit-tools --no-save --package-lock=false playwright@1.58.2 lighthouse@12.8.2
node tools/lab3-checks.mjs
node tools/lab3-browser.mjs
node tools/lab3-lighthouse.mjs
```

Скрипты используют порты 8131, 8132 и 9243; сами запускают и закрывают свои серверы/браузеры. Функциональный аудит проверяет URL с origin `http://127.0.0.1:8131`. Повторные запуски обновляют файлы доказательств. `tools/make-covers.mjs` нужен только для пересоздания уже включённых в Git изображений.

## Границы и сдача

- Нет блокирующих проблем в обязательной функциональности ЛР3 по выполненным проверкам. Тесты проводились в Edge, не в Safari/Firefox и не с экранным диктором.
- Учебные данные не претендуют на подтверждённую библиографию; рейтинг и доступность условные.
- `book.html` и `loan.html` остаются демонстрационными страницами Solaris. Обработка отзывов/выдач backend-сервером не относится к ЛР3; ссылка detail показывается только для Solaris.
- localStorage зависит от origin и настроек браузера. Синхронизация уже открытых вкладок не добавлена; новая вкладка и reload восстанавливают последнее сохранение.
- Выданная преподавателем ESLint-конфигурация отсутствует. Чистый результат относится к приложенному `eslint.config.js`.
- Защита: студент должен показать сочетание фильтров и reload, поставить breakpoint в делегированном обработчике, объяснить `event.target`, `closest`, чистоту lib, безопасную запись DOM и обработку storage.
- PR ЛР1/ЛР2 ожидают проверки. До их включения в main полный diff с main содержит предыдущие работы; изолированный diff ЛР3: `git diff lab-2/styles...lab-3/js-app`.
- Push, merge, rebase и создание PR не выполнялись. Подготовлено [описание PR](../lab3-pr.md).
- Дополнительные задания (подсветка совпадений, импорт/экспорт, hash-синхронизация, виртуализация) не реализованы. ЛР4 не начата.
