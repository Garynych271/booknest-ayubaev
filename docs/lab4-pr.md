# ЛР4: Open Library REST API для BookNest

## Изменения

- API-клиент с BASE_URL, URLSearchParams, response.ok и ApiError.status; fetch только в api/.
- Поиск по названию/автору, debounce 350 мс, минимум 2 символа, серверные фильтры/сортировки.
- Loading / success / empty / error, разные ошибки сети/4xx/5xx, Retry и тайм-аут без зависания.
- AbortController + защита от устаревших ответов, finally, Promise.all для деталей.
- Пагинация по 20 API-записей с блокировкой границ; детали по стабильному work ID и 404.
- Wishlist v2 с безопасным чтением/записью и миграцией v1 без удаления старых данных.
- Сохранены темы, адаптивность и чистые функции ЛР3; React/TypeScript/backend не добавлены.
- Коллекция Postman, воспроизводимые аудиты, README и AI_USAGE.

## Проверка

```powershell
npm ci
npm test
npm run lint
npm start
```

Открыть http://127.0.0.1:8130/, ввести Solaris, добавить в wishlist, перейти на вторую страницу и открыть детали. Проверить Offline → Retry, ошибочный `book.html?id=OL999999999999999W`, темы и Tab.

Результаты: **17/17 unit**, **0 ESLint errors/warnings**, **6/6 реальных API browser-сценариев**, **11/11 мок-сценариев**, **24/24 размеров/тем без overflow**. Lighthouse Accessibility snapshot: каталог и детали, light/dark — **100/100 во всех четырёх проверках**. Performance не измерялся.

Реальные curl: 200 (поиск), 200 (Solaris), 404 (несуществующий work). Отмена подтверждена CDP canceled=true. Сохранены 26 скриншотов, HTTP-ответы и JSON/HTML Lighthouse. Подробности, команды и ранние неуспешные попытки: [docs/lab4/README.md](lab4/README.md).

- [x] Обязательная реализация ЛР4, без перехода к ЛР5.
