# ЛР4: интеграция с внешним REST API

Дата: 17.10.2026 (Asia/Qyzylorda, UTC+5; время в JSON указано в UTC). Ветка `lab-4/api` от `lab-3/js-app`, базовый коммит `51b8886`. Предыдущие ветки и история не изменялись.

## Выполненные требования

| Требование | Реализация / доказательство |
| --- | --- |
| Настоящий Open Library, без локального fallback | `api/books.js`; реальные HTTP-ответы в `network/` |
| BASE_URL, URLSearchParams, response.ok, ApiError.status | `api/client.js`; `tests/api.test.js` |
| async/await, try/catch/finally | API-клиент и `lib/api-state.js`; loading снимается в finally только актуального запроса |
| AbortController, AbortError без пользовательской ошибки | Немедленная отмена при вводе + номер запроса; `Network.loadingFailed`, canceled=true в `network/browser-real.json` |
| Promise.all | Независимые запросы произведения и поисковых метаданных по одному work ID; тест подтверждает одновременный старт |
| fetch только в API | Единственный вызов в `api/client.js`; запрет глобального fetch в остальных модулях ESLint |
| Debounce и минимум запроса | 350 мс, 2 символа после trim; подтверждены мок-проверкой отсутствия лишних запросов |
| Четыре исключающих состояния | `[data-state]`, один state/render на HTML-страницу; проверено по computed display, не только hidden |
| Сеть / 4xx / 5xx / Retry | Реальные Offline/404, воспроизводимые 429/503; отдельный настоящий 500 сохранён как неудачный эксперимент |
| Пагинация | limit=20, page от 1, блокировка границ; реальная страница 2, мок последней страницы и восстановления после reload |
| Детали и 404 | `book.html?id=OL109524W`, work JSON + метаданные, некорректные ID отвергаются, отдельный реальный 404 |
| Wishlist в localStorage | Стабильные OL…W и снимки названия/автора; сохранён после смены страницы, reload, перехода к деталям |
| Темы и адаптивность | 24 комбинации: 3 страницы × 4 ширины × 2 темы; overflow отсутствует |
| Коллекция / скриншоты | `api-collection.json` (Postman v2.1), 26 настоящих снимков Edge, режимы real/mock в именах |

Поиск ограничен названием/автором; жанры отображаются в subject-запросы: science fiction, fiction, nonfiction, history, programming. «Роман» соответствует широкой категории fiction, не строгой литературоведческой классификации. Сортировки серверные: title, new, rating. Rating использует порядок Open Library, не пересортировку одной страницы по округлённой оценке.

Доступность означает `ebook_access:public`, а не наличие экземпляра в университетском клубе. Старые учебные отзывы Solaris удалены из динамической detail-страницы, чтобы не приписывать их другим произведениям. `loan.html` сохранён как учебная форма Solaris без серверной отправки.

Среда: Node.js 22.14.0, Edge 155.0.4283.45, Playwright 1.58.2, Lighthouse 12.8.2. Локальная раздача: 127.0.0.1:8134 для браузерных тестов, :8135 для Lighthouse.

| ESLint | Exit 0, 0 ошибок / предупреждений | `eslint.json` |
| Реальные curl.exe GET | Поиск 200, Solaris 200, отсутствующее произведение 404 | `network/curl-summary.json`, три `.http.txt` |

Lighthouse запускался в режиме **snapshot** на уже загруженных реальных данных, не на моках. Во всех четырёх итоговых снимках проверены success и фактическая тема. Это проверка Accessibility, **не измерение Performance**. Оценки ЛР3 не переносятся на ЛР4.

Шесть реальных сценариев: обычный поиск; Slow 4G + отмена; переход к странице 2; Offline + Retry; Solaris; ошибочный work URL. В финальном поиске Solaris API вернул 20 записей, из них 19 корректных work ID. Это показано пользователю, а не подменено фикстурой.

Slow 4G эмулировался CDP: latency=2000 мс, download=200000 байт/с, upload=93750 байт/с, cellular4g. Это явно заданный профиль, не физическая мобильная сеть и не заявление о точном совпадении с пресетом каждой версии DevTools. Для Offline использован `Network.emulateNetworkConditions` с offline=true, страница уже загружена. Журнал содержит настоящее `net::ERR_ABORTED`, canceled=true для поиска Lem, заменённого Tolkien.

Ошибки ресурсов при намеренном Offline/404 и при моках 429/503 присутствуют в consoleErrors/realConsoleErrors. Они ожидаемы и не скрывались. Утверждение «консоль всегда полностью пуста» неверно; необработанных исключений приложения не обнаружено.

## Исправления и ограничения

1. Первый аудит выявил перекрытие hidden стилем Grid: error и success могли отображаться вместе. Усилен селектор hidden; повторный аудит подтвердил исключительность. Исходный отчёт: `browser-results-before-fixes.json`.
2. Open Library возвращает и повреждённые ключи вида `/works/OL19413970M`. Проверка work ID исключает их, счётчик показывает пропуски. Пагинация по-прежнему использует 20 **исходных API-записей**; поэтому карточек может быть меньше. Автоматическое заполнение выдуманными/локальными книгами не используется.
3. Попытка отфильтровать такие ключи wildcard на сервере дала настоящий 500. Неподходящий фильтр удалён; сохранены `network/unsupported-wildcard-500.http.txt` и `wildcard-attempt.json`. Итоговый стандартный поиск даёт 200.
4. Исправлены позиции Grid деталей, восстановление после pagehide/pageshow и показ пустых изображений. Сценарий восстановления использует синтетические PageTransitionEvent: это не доказательство фактического попадания страницы в BFCache.
5. Обложка Solaris не завершила загрузку за 8 секунд ожидания: complete=false, naturalWidth=0, hidden=true в реальном отчёте. Обложки зависят от внешнего сервиса; каталог/детали не ожидают их для снятия loading. Полная загрузка всех внешних обложек не объявляется проверенной.
6. Первый Lighthouse-аудит тёмного каталога дописывал Solaris к сохранённому запросу и снимал empty. Исправлен сам сценарий, итоговые четыре аудита относятся к success. Исторический `summary-before-audit-fix.json` не выдаётся за проверку загруженного каталога.
7. v1 wishlist мигрирует без удаления старого ключа. Локальные b-ID остаются с отметкой «список ЛР3»; автоматическое угадывание OL-ID не выполняется. Новые записи используют стабильный work ID и доступны из списка вне выдачи.
8. Реальные 429/503 специально не провоцировались нагрузкой; проверены моками. Некорректные данные/тайм-аут/запрет хранилища также тестовые условия. API-коллекция подготовлена, но GUI Thunder Client/Postman не запускался.

## Воспроизведение

Обычные проверки:

```powershell
npm ci
npm test
npm run lint
node tools/lab4-checks.mjs
node tools/lab4-api-checks.mjs
```

Аудитные пакеты не являются зависимостями приложения. В чистой копии проекта установить отдельно:

```powershell
npm install --prefix .audit-tools --no-save playwright@1.58.2 lighthouse@12.8.2 puppeteer-core
node tools/lab4-browser.mjs
node tools/lab4-accessibility.mjs
```

Нужен установленный Edge по пути `C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`, свободные порты 8134/8135/9245 и доступ к openlibrary.org/covers.openlibrary.org. Аудиты сами закрывают свои браузеры и серверы в finally. Генерируемые результаты будут обновлены; прошлые оценки не гарантируют результат нового сетевого запуска. В ограниченной среде может понадобиться разрешение запуска браузера/сети.

## Перед сдачей

- Импортировать `api-collection.json` в Postman (Import → File), выполнить search/work/missing, если преподаватель требует демонстрацию именно GUI. Реальные запросы в этой работе выполнены curl.exe и браузером, не Thunder Client.
- Открыть приложение через `npm start`, ввести Solaris, проверить wishlist и детали; объяснить код на защите.
- Для Network-доказательства включить Preserve log, выбрать Slow 4G, ввести Lem, дождаться запроса и заменить на Tolkien. Старый запрос должен отмениться. Уже сохранённый CDP-журнал подтверждает автоматизированную проверку.
- Только после отдельного разрешения выполнить push и создать PR; описание подготовлено в `../lab4-pr.md`.
- Учесть незамёрженные ЛР1–3. Чистый объём: `git diff lab-3/js-app...lab-4/api`. Итоговая base по syllabus — main; при обычном merge предшествующих веток дифф станет корректным. Squash-зависимость нужно обсудить отдельно, историю автоматически не переписывать.

Код и доступные проверки ЛР4 завершены. Не выполнены ассистентом: демонстрация в GUI-клиенте, защита/приёмка, push и публикация PR. Дополнительные cache/automatic retry/load more/Promise.allSettled не реализованы, ЛР5 не начиналась.
