# ЛР6A: типизированные хуки и Context BookNest

Сетевой lifecycle BookNest вынесен из React-компонентов в собственные типизированные хуки. Добавлены Context для темы и локального текущего пользователя без функций части B.

## Что сделано

- Реализованы `useFetch<T>`, `useBooks`, `useBook` и `useDebounce<T>`.
- `useFetch` управляет loading/error/data, Retry, AbortController и cleanup.
- Каталог и детали больше не импортируют API-функции и не знают про HTTP.
- Добавлены ThemeContext с сохраняемым переключателем и AuthContext с локальной заглушкой читателя.
- Контексты не содержат фильтры, wishlist, ответы API или состояния страниц.
- Сохранены Open Library, поиск, фильтры, пагинация, детали, wishlist, адаптивность и доступность ЛР5.
- React Router, Zod, react-hook-form, login и защищённые маршруты не добавлялись.

## Как проверить

```powershell
cd booknest-web
npm ci
npm run typecheck
npm run lint
npm test
npm run build
npm run dev
```

Проверить быстрый ввод, смену фильтров, Retry после Offline, детали, wishlist после reload и переключатель темы. Полные команды и доказательства: `docs/lab6a/README.md`.
