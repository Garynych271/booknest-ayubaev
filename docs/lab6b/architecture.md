# ЛР6B: план маршрутизации и форм

План составлен до реализации 17.10.2026. Ветка `lab-6b/router-forms` создана от `lab-6a/hooks` (`63053b8`). ЛР7 и реальный backend не входят в работу.

## Слои

```text
src/
├── app/       # Routes, общий layout, RequireAuth, сборка состояния wishlist
├── pages/     # компоненты маршрутов
├── features/  # каталог, детали, wishlist, форма книги
├── shared/    # UI, Context, общие hooks и browser storage
├── api/       # Open Library read API и учебный локальный write adapter
└── types.ts   # общие предметные типы
```

Направление зависимостей: `app → pages → features → shared/api → types`. `shared` не импортирует страницы или features. Компоненты не вызывают `fetch`; каталог и детали сохраняют hooks ЛР6A.

## Маршруты

| Путь | Страница |
| --- | --- |
| `/books` | каталог; `q`, `genre`, `available`, `sort`, `page` в query string |
| `/books/:bookId` | детали Open Library или созданной локальной записи |
| `/books/new` | единая форма в режиме create |
| `/books/:bookId/edit` | та же форма в режиме edit с загрузкой и prefill |
| `/wishlist` | `RequireAuth`, список желаемого |
| `/login` | локальная заглушка входа/выхода |
| `/loan` | сохранённая учебная форма ЛР1–5 для функционального паритета |
| `*` | полноценная страница 404 |

Корневой `/` перенаправляет на `/books`. Общий `AppLayout` содержит Header, `Outlet` и Footer. Wishlist передаётся маршрутам обычными props из `App`, не через Context.

## Форма и mock API

Единая Zod-схема содержит 8 полей: название, автор, жанр, ISBN, год, дата выдачи, срок возврата и описание. Тип выводится через `z.infer`; `dueDate` должен быть позже `issuedDate`.

`api/bookRecords.ts` является учебным локальным adapter, а не Open Library и не backend:

- хранит записи текущего origin в `localStorage`;
- создаёт ID вида `BN-*` и возвращает запись после задержки;
- возвращает типизированные mock 422 для специального серверного правила;
- возвращает 409 при повторном ISBN;
- поддерживает общий сбой для проверки ошибки формы;
- принимает `AbortSignal` для cleanup загрузки/отправки.

Open Library используется только для поиска и чтения исходных деталей. При редактировании внешней книги её данные предзаполняют форму, а сохранённая версия становится локальной записью с тем же маршрутом.

## Границы

Не добавляются backend, JWT, реальная регистрация, оптимистичные обновления, защита несохранённых изменений, lazy routes и функции ЛР7.
