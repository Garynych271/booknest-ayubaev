# Практики 2–7: проверяемые артефакты BookNest

Подготовлены отдельные отчёты и коммиты для обязательных заданий практик 2–7. Исторические реализации ЛР1–6 переиспользованы без переноса vanilla JS на React задним числом; новые измерения отделены от ранее сохранённых доказательств.

## Состав PR

- Практика 2: семантика, формы, breadcrumbs, W3C, клавиатура и Accessibility.
- Практика 3: токены, Grid/Flexbox, адаптивность, темы и CSS-debug отчёт.
- Практика 4: `selectBooks`, экспортируемый `renderBooks`, state/render, делегирование и CDP breakpoint.
- Практика 5: настоящий Open Library API, четыре UI-состояния, debounce, AbortController, Retry и пагинация.
- Практика 6: React-декомпозиция, типизированные props, владельцы состояния, keys и React DevTools.
- Практика 7: собственные хуки, API-слой, cleanup, exhaustive-deps и измерение debounce 6:1.
- Общая матрица: `docs/practices/README.md`.
