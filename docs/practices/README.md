## Ручные действия

1. Получить у преподавателя PNG для практики 2 и `broken.css` для практики 3, затем дополнить соответствующие отчёты реальными результатами.
2. Нарисовать требуемые бумажные схемы DOM и React-компонентов.
3. На защите импортировать коллекцию API в Thunder Client/Postman и показать запросы.
4. Снять вручную Network до/после debounce и записать React Profiler; неудачные автоматические изображения доказательствами не считаются.
5. Согласовать AuthContext: практика 7 просит Context только для темы, а ЛР6A отдельно требует локальный AuthContext. В рабочем приложении сохранены оба контекста, данные каталога в них не помещены.
